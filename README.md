# CrowdPulse-Tableau-Dashboard

## 📊 CrowdPulse – Crowdfunding Performance & Success Insights (Tableau)

This repository contains interactive Tableau dashboards built using a global crowdfunding dataset (2009–2019).  
The dashboards analyze campaign outcomes, success rates, funding behavior, and category performance using a highly interactive, visual-driven design.

## 🎯 Project Objectives
- Analyze overall crowdfunding success rate and campaign outcomes
- Understand funding performance across different goal ranges
- Identify top-performing and underperforming categories and sub-categories
- Explore country-wise and time-based trends
- Highlight top projects by backers and funds raised
- Enable exploratory analysis through visual interactions and minimal filters

## 🛠 Tools & Technologies
- Tableau Desktop (Public Edition)
- Crowdfunding Dataset (2009–2019)
- Calculated Fields
- Dashboard Actions
- Visual-Based Filtering Design

## 🧩 Dashboard Features & Interactivity

### 🔹 Visual-Based Filtering
Most interactivity in this project is driven directly through the visuals.  
Clicking on bars, segments, or chart elements dynamically filters:
- KPIs
- Related charts
- Trend views

This reduces reliance on traditional filter panels and encourages exploratory analysis.

### 🔹 Dashboard-Level Filters
A limited set of dashboard-level filters is used to control:
- Year
- Country
- Month

These filters apply consistently across all visuals without cluttering the dashboard layout.

### 🔹 Consistent KPI Framework
Key metrics remain consistent across both dashboards:
- Success Rate
- Funds Raised
- Number of Backers
- Campaign Duration

This allows the same KPIs to be analyzed from multiple perspectives without changing the underlying logic.

## 📈 Key Insights
- Campaigns with mid-range goals ($10K–$50K) dominate successful outcomes
- Success rates vary more by sub-category than by main category
- A small number of projects attract a disproportionate share of backers and funds
- Crowdfunding activity peaked around 2014 and later stabilized
- Very high funding goals attract attention but convert less consistently
